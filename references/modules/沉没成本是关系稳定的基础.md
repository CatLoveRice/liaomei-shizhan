# 🏷️ 沉没成本是关系稳定的基础

> **核心命题：** 恋爱关系的稳定性，不取决于你投入了多少，取决于**她投入了多少**。没有重大沉没成本的关系，她离开时不会犹豫——因为什么都没放进去，走了也不亏。

---

## 一、定律

**沉没成本决定去留阈限：** 一个人在一段关系中的沉没成本越高，她离开的心理门槛就越高。不是因为她道德上觉得"应该留下"，而是因为离开意味着否定自己之前的所有投入——没人愿意承认自己为不值得的人付出了那么多。

关系的稳定性公式：
```
稳定性 ≈ 她的沉没成本 - 你的沉没成本
```
当她的沉没成本远大于你的沉没成本时，关系最稳。因为你的投入可以被视为"自发的"，而她的投入是不可收回的。

## 二、三个关键维度

### 1. 情绪投资

她为你产生的每一次情绪波动——等待、焦虑、开心、担心、想念——都是投资。你让她产生情绪的频次和深度，决定了她的情绪沉没成本。

这就是为什么——
- 秒回的男人不被珍惜（她的情绪成本为零）
- 让她等待、让她猜测、让她"搞不明白"的男人，她在不断投资

### 2. 行为投资

她主动为你做的事情——约你、送你东西、为你改变计划、在你身上花时间——都是不可收回的投资。

关键区分：
- ❌ **她回应你的需求**（被动）→ 沉没成本低
- ✅ **她主动为你做事**（主动）→ 沉没成本高

### 3. 心理投资

她在心里为你留的位置——拒绝别人时想到你、做决定时考虑你的看法、把你放进她的未来假设里——这些看不见的投入是最难收回的。

信号包括：
- 她开始解释自己的行为（"我和XXX吃饭，还有个哥哥"）
- 她考虑你的感受后才做决定
- 她在社交媒体上的内容是你能看到的

## 三、实操意义

### 追求阶段不要替她投资

最常见的错误：男生在追求阶段替女生把所有的沉没成本交了。

- 你请客吃饭 × → 你的沉没成本，不是她的
- 你等她回复 × → 你的沉没成本，不是她的
- 你为她准备惊喜 × → 你的沉没成本，不是她的

**正确的做法：让她在你身上投资。**

- 让她主动找你聊天 → 她投资了时间
- 让她为你付出注意力 → 她投资了情绪
- 让她思考"他什么意思" → 她投资了心理资源
- 让她主动约你 → 她投资了行动

### "疯狂找你"的价值

如果一个女孩在你疏远后疯狂找你，那个过程就是她在为自己的选择缴纳沉没成本。她找你找得越疯，她以后就越难放手——因为放手意味着否定自己那段"疯狂"的行为。

```
没有沉没成本 → 没有犹豫 → 随时可走
有沉没成本 → 有离开门槛 → 关系稳
```

### 追求与关系的分界

- **追求阶段：** 你在投资，她在观察
- **关系阶段：** 双方都在投资

但最健康的关系模型是——**在追求阶段就开始让她投资**。不是让她追你，是让她在互动中不知不觉地投入注意力、情绪和行动。到关系确立时，她的沉没成本已经足够让她不会轻易离开了。
