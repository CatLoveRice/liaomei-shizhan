# 🏷️ 三答三问沟通法

*   **分类目录：** [[03-话术工程与场景沟通/MOC_话术工程]]
*   **适用阶段：** 初识 / 搭讪后 / 约会聊天
*   **核心标签：** #沟通实战/话术模板 #社交技巧/初识破冰
*   **原始出处：** 猎手话术网（2009，湖南台《搭讪班传奇》）

## 🔬 一、底层心理机制 (The "Why")

> **没经过训练的搭讪者最常见的错误：查户口。** 开场白之后一上来就是"你是哪里人？什么专业？读几年级？"——这是**非常不符合社交礼仪**的。你又不是记者，凭什么一上来就问一堆问题？

三答三问的核心逻辑是：**想要认识她，必须先让她认识你。**

底层心理机制：**互惠原则 + 社交公平感。** 当你先分享自己的信息（答），对方潜意识会感到"公平压力"——该轮到我了。同时，你的分享也降低了她的戒备：你愿意暴露自己的信息，说明你没有恶意。

类比：你去面试，给你五分钟时间，你会问考官"你是哪里人？什么部门？"吗？不会。这些可以等争取到机会后再慢慢了解。**先展示自己，再了解对方。**

## 🛠️ 二、标准操作程序 (The "How" — SOP)

### 核心公式

> **开场白 → 抛出自己（答） → 问题丢给她（问） → 抛出自己（答） → 问题丢给她（问）……**

每问一个问题之前，**先回答自己的对应部分**。

### 操作结构对比

**❌ 错误模式（查户口）：**
```
你：你是哪里人？
她：广州人。
你：你是做什么工作的？
她：会计。
你：你多大了？
她：24。
```
→ 她心里：你是谁呀？凭什么问我这么多？

**✅ 正确模式（三答三问）：**
```
你：我是小宝，朋友们都叫我阿扁，因为我的头是扁的（给她看），小时候没睡好……
你：我是做网站的。你呢？
她：圈圈。
你：我上班的地方有一只小猫，很可爱，有一次……
```

### 关键要点

1. **不要贪图省事用几个字回答**——你省事，她就更省事，一样聊不开
2. **延展开去，说得有趣些**——最好跟一个故事连起来
3. **开场三部曲：** 开场白 + 三答三问 → 清楚表明来意并消除不安全感 → 正常对话
4. **如果三答三问后仍然聊不开**——考虑一下她是不是你的型，要号码识相离开也不尴尬

## 💬 三、实战话术案例

### 案例：街头直接开场（来自猎手示范）

| 步骤 | 对话 | 操作要点 |
|------|------|---------|
| 开场白 | "嗨！其实是我想要认识你。" | 直接表达意图 |
| 破冰 | "看见你走过，觉得你很特别，想过来和你认识一下。你是走这边吗？" | 加一句情境关联 |
| 答+问 | "我叫小宝，你呢？" | 先给名字再问 |
| 答+延伸 | "其实我国语的朋友都叫我小扁，因为我的头是扁的，你看是不是（给她看），小时候没睡好，还好啦，他们没叫我阿扁……" | 自嘲延伸，打开话题 |
| 答+问 | "我是做网站的。你呢？" | 先分享再问 |
| 持续循环 | "我上班的地方有一只小猫……" → 继续答+问 | 故事承接 |

### 变异型：如果她话很少

不需要让她说太多。**在初始阶段，你有责任引导对话**（因为是你开启的）。如果她不愿意多说，你持续用"答+问"模式提供信息，给她空间。三答三问后如果还是打不开，说明可能不合适，可以礼貌收号离开。

## 📊 模式变体

| 场景 | 操作 |
|------|------|
| 街头搭讪 | "我叫XX，是做XX的。你呢？" + 延伸话题 |
| 聚会社交 | "我是XX的朋友，我们都是XX认识的。我最近在……" |
| 线上聊天 | "我刚在看一部电影，讲的是……你有没有看过什么好片？" |
| 相亲开场 | "我平时喜欢……其实是因为……你平时有什么爱好？" |

## ⚠️ 高危红线

1. **❌ 变成背书：** 一连串自我介绍像背简历 → 她失去兴趣。要穿插提问，形成互动
2. **❌ 三问不三答：** 连续问三个问题却不分享自己 → 查户口感
3. **❌ 答得太短：** "我是做IT的" → 话题终结。应该延展：为什么做IT、有趣的事、行业八卦
4. **❌ 忘记场景转换：** 三答三问只适用于初识阶段，关系升级后需要更深度的互动模式
