# 06 · 四分支回应引擎与长期关系稳态

## 一、每次出手前的四分支预案（避免发完就慌）

任何一次主动发消息、邀约、推拉或亮底线，出手前先想好对方 4 种反应对应的接法：
1. **积极回应（秒回/接梗/主动约）**：匹配对方温度，稳住节奏，**绝不瞬间爆棚表白或过度加码**；顺势敲定下一次线下见面。
2. **含糊打太极（“看情况”“改天”“最近忙”）**：礼貌收场（“行，那你先忙”），**立刻撤回注意力与主动供给**，等对方主动补位。
3. **冷淡敷衍/不回（只回单字或超过 24–48 小时不回）**：绝不连发追问、绝不发问号；进入 3–7 天静默观察窗。连续 3 次敷衍立即暂停联系。
4. **明确拒绝或闪避**：一句话体面退场，**24 小时内零解释、零补救、零道歉**，尊重边界直接翻篇。

## 二、在一起后的长期关系稳态（防姿态下滑）

很多男生追到手前情绪极稳、颇有魅力，确立关系后却迅速失衡崩盘，核心原因是踩了以下四条红线：

1. **需求感回流（把伴侣当成唯一情绪开关）**
   - 确立关系后立刻推掉自己的事业节奏、社交圈与爱好，24 小时围着对方转 → 稀缺感瞬间清零。
   - **稳态做法**：始终保留自己的主线目标、独立朋友圈与固定运动/兴趣习惯，让她持续看到一个向上生长、有自己世界的男人。
2. **从“呈现价值”滑向“控制与查岗”**
   - 害怕失去导致过度盘问行踪、情绪化吃醋 → 把伴侣推远。
   - **稳态做法**：用清晰可执行的双方边界规则代替审讯查岗；红线以内充分信任，触碰底线平静执行一次性规则。
3. **停止情绪价值供给，进入“理所当然”模式**
   - 觉得“已经是自己人了”，不再注意仪表、说话变得敷衍不耐烦、彻底取消约会仪式感。
   - **稳态做法**：定期制造低成本高质量的专属约会体验，记住她近期的具体偏好与小成就，保持克制而稳定的偏爱。
4. **冲突处理铁律（一次性规则 + 就事论事）**
   - 吵架不翻旧账、不做人身攻击、不玩冷战消失；情绪上头时先约定冷静 30 分钟，平稳后只解决具体事实与后续规则，绝不用“提分手”当威胁筹码。
