# 03 · 线上聊天与约会推进全流程

## 一、破冰与深度聊天原则（去“查户口”）
1. **三答三问法**：想了解对方，必须先主动分享自己的真实经历或观点（答），再自然抛问题（问），用互惠降低戒备，避免连环盘问。
2. **话块连情（四层递进）**：听话抓关键词延伸，但不要停在事实问答（高级查户口），逐步过渡到：
   - **表层事实 → 情绪词 → 隐含价值观 → 个人经历共鸣**
   - 铁律：始终保持双方自我暴露对等，不单方面交底。
3. **假定回答法（去卑微试探）**：
   - 邀约用确定、自然的陈述（“周六去那家店，一起吧”），代替卑微试探（“如果你刚好有空、方便的话能不能……”）；
   - 遭拒则大方收场（“没关系，那改天”），绝不纠缠追问。

## 二、线上沟通四条铁律
1. **工具定位**：微信只负责“维持连接 + 敲定见面”，不要试图靠打字谈恋爱。
2. **节奏匹配**：回复长度与频率大致匹配对方，每条留一个自然可接的生活钩子。
3. **严禁小作文与线上表白**：深度情绪沟通与矛盾解决必须见面或语音；发长篇大论质问等于把低位写死。
4. **连续敷衍止损线**：连续 **3 次** 敷衍无实质回应（只回“嗯/哦/哈哈”且不接茬）→ **立即暂停主动联系**。

## 三、明确邀约终结长期模糊
当关系陷入长时间暧昧拉扯、对方忽冷忽热时，别靠猜心思或刷朋友圈耗着，直接发起一次**说得明白、份量不重、对方随时能退**的明确邀约（如“明天在你这边，晚上有空一起吃饭吗，没空就算了”）：要么实质推进，要么拿到明确态度止损。

## 四、约会设计与肢体升级（安全感优先）
1. **约会三条腿**：兼顾“吸引（见识与松弛感）+ 舒适（轻松不尴尬的聊天氛围）+ 情绪张力（适度转场与互动）”。
2. **渐进确认阶梯**：遵循“无意识轻触 → 社交轻触 → 引导牵手 → 拥抱”的节奏，**绝对前提是对方已进入舒适区且无躲闪**。
3. **退让红线**：若对方出现轻微闪避或僵硬，立刻自然收回、语气如常继续聊天，绝不质问“你紧张吗”或强行跳步。
